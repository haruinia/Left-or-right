# 左右 · ZUOYOU

思路，就在旁边。左右是一款本地优先的桌面截图学习助手：截取眼前的题目，向自己配置的模型提问，在悬浮窗中阅读流式解答。

## 当前功能

- 截图提问、连续追问和流式回答；单次最多发送 8 张图片。
- 默认完整解答并优先展示答案，可左右切换答案、代码和思路；支持公式、代码高亮和翻页阅读。
- 设置专业方向、编程语言、回答语言和讲解方式；可选择先给提示、分步讲解或完整解答。
- 在设置页管理模型接入、面试资料、快捷键和学习记录。
- 保存会话与笔试记录，回看题图和回答，并导出 Markdown 或整理到知识库。

## 桌面应用

安装版自带本地服务。打开应用后自动启动 `9958`，从应用的“更多设置”打开应用内设置窗口，无需额外启动终端服务。退出应用只停止它自己启动的服务。

悬浮窗默认鼠标穿透：macOS 按住 `⌘`、Windows 按住 `Ctrl` 才能操作，松开即恢复穿透，未按住时没有悬停反馈。应用内设置窗口正常接收鼠标和键盘，不需要一直按住修饰键。

### 捕获保护与分享边界

主悬浮窗、应用内设置窗口及截图选区窗均请求系统窗口捕获保护。应用内下拉菜单在同一网页窗口中绘制，避免另开原生系统菜单弹层。快捷键 `⌘B`（Windows 为 `Ctrl+B`）隐藏或恢复左右的全部窗口；隐藏后，单独按住修饰键不会重新显示它们。截图期间也会暂时隐藏主窗和设置窗。

这不是对所有截图、会议共享或录屏的不可见保证：macOS 的部分 ScreenCaptureKit 捕获方式可能不遵守窗口排除标记；Windows 10 2004 及更新版本使用系统的窗口排除捕获能力，旧版本可能只显示黑块，具体软件及系统仍需实测。不支持的平台或录屏方式不会被声称为已保护，也不会通过驱动、注入或降低系统策略绕过限制。

涉及敏感内容时优先只共享目标业务窗口，不共享整个桌面；必要时先隐藏左右的全部窗口。手动在外部浏览器打开 `http://127.0.0.1:9958/settings` 不具备 App 窗口捕获保护。

### 跨设备与跨系统

Windows 与 macOS 共用模型接入、专业方向、语言、对话和学习记录接口；显示器为单选运行屏幕，截图跟随应用所在屏幕，并按每块屏幕的缩放比例转换选区坐标。Windows 安装包与后台服务必须在 Windows 原生构建，不能把 Mac 后台可执行文件复制过去使用。

数据保存在当前设备的用户目录，不会自动跨设备同步密钥、简历或学习记录。换设备需自行配置接口或导入配置；请勿通过 Git 同步 `.env`、数据库或密钥。Windows 的原生安装、不同 DPI、会议录屏和鼠标穿透行为需要 Windows 实机验收，模拟单测不能替代。

### 运行显示器

在快捷设置的**运行显示器**下拉框中选择一块屏幕，应用会移动过去，后续截图跟随应用所在屏幕。两个显示器不能同时选中；截图屏幕与应用运行屏幕不是两套独立设置。

### 常用快捷键

| 操作 | macOS 默认键位 |
|---|---|
| 截图 | `⌘H` |
| 发送截图 | `⌘Enter` |
| 隐藏 / 显示 | `⌘B` |
| 新对话 | `⌘N` |
| 重置并开始新对话 | `⌘R` |
| 清空截图 | `⌘⇧Backspace` |
| 退出应用 | `⌘Q` |

完整键位可在设置页查看和修改。保存后自动同步到桌面应用；系统占用的组合键会提示冲突。

默认使用全屏截图，也可在快捷设置中改为局部截图。等待分析只在尚未返回正文时显示于回答面板；不再提供独立停止按钮，重置会中断当前生成、保存已有会话并开始新对话。

首次截图需要在 macOS“系统设置 → 隐私与安全性 → 屏幕录制”中授权左右。

## 模型接入

从应用打开设置页，在“模型接入”中填写：

1. 名称，用于区分不同来源，例如“个人接口”或“公司网关”。
2. 接口 URL，例如 `https://api.example.com/v1`。
3. API Key。
4. 接口提供的模型名称。

模型卡片按名称展示，同名模型可以分别保存不同来源。在桌面快捷设置的“当前模型”中直接选择已保存的接入，点击“刷新”更新列表；新增或编辑接入在完整设置页进行。

点击“保存并使用”后，从下一次提问开始使用。协议根据接口路径自动识别，单次输出额度默认 **30,000 tokens**；也可导入 JSON 配置，导入本身不会切换当前模型。

已保存的 API Key 默认以星号遮罩显示，点击小眼睛图标查看或隐藏。不需要清空密钥来表示“保持原值”。

测试连接用于确认接口可访问；真实截图问答还需要所选模型支持对应的输入类型。`mock` 是本地演示模式，不代表真实模型已经接通。

## 设置与记录

- **答题偏好**：专业方向、编程语言、回答语言、讲解方式和复习目标。网页与 App 共用完整下拉选项，方向分为技术与工程、考试与资格、综合学习；行测、申论等位于考试组，也可填写自定义方向和语言。快捷设置顶部可直接切换专业方向。保存后从下一次提问生效；考试类方向禁用但保留已选编程语言，切回技术方向即可恢复，不会把语言要求附带给考试题。
- **面试资料**：保存岗位 JD 和简历，支持 PDF、Word、图片 OCR 与文本导入，单文件上限 25MB。这些资料不会自动附加到截图笔试问题中。
- **学习记录**：查看笔试记录、会话记录和知识库，删除不需要的条目或导出 Markdown。
- **快捷键**：点击键位录入新组合，支持冲突检查与恢复默认。

## 从源码运行

需要 Python 3.11+。创建并激活虚拟环境后安装依赖：

```bash
python3 -m venv .venv
```

```bash
source .venv/bin/activate
```

```bash
pip install -e ".[dev]"
```

```bash
python scripts/run_gateway.py
```

开发服务地址：

| 地址 | 用途 |
|---|---|
| `http://127.0.0.1:9958/` | 截图问答首页 |
| `http://127.0.0.1:9958/settings` | 模型、偏好、记录与快捷键 |
| `http://127.0.0.1:9958/docs` | 本地 API 文档 |

端口被占用时可用 `python scripts/run_gateway.py --port 9959`，桌面配置中的 `gatewayUrl` 需与之保持一致。安装版应用不需要执行这些开发命令。

### 构建桌面应用

在目标操作系统上准备 Node.js、npm 与已激活的 Python 环境；macOS 使用 `.venv/bin/python`，Windows 使用 `.venv\Scripts\python.exe`。Windows 默认构建 x64 安装包，macOS 构建当前机器架构：

Windows 的任务栏隐藏策略需要[定制 Electron 运行时](desktop/electron/README.md)。先按该文档构建并设置 `ZUOYOU_ELECTRON_DIST`，再执行 `dist:win`；Windows 开发使用 `start:win`。普通 Electron 会被能力检查拒绝，避免打包出 Ctrl 操作时重新出现任务栏按钮的版本。

```bash
pip install -e ".[desktop]"
```

```bash
npm --prefix desktop ci
```

```bash
npm --prefix desktop run dist
```

`npm --prefix desktop run dist` 按当前系统构建；也可在对应系统执行 `dist:mac` 或 `dist:win`。Windows 生成按用户安装的 NSIS 安装包，后台服务与修饰键助手隐藏控制台启动，卸载不自动删除用户数据。没有签名证书的构建仍可能触发系统安全提示，不应关闭安全检查来掩盖它。

构建时会打包本地服务及其运行环境，安装后不依赖开发机的 Python。仅生成应用目录时使用：

```bash
npm --prefix desktop run dist -- --dir
```

可通过 `DESKTOP_PYTHON` 指定构建使用的解释器。构建产物位于 `desktop/dist/`，不应作为源码提交。仓库提供手动触发的原生桌面构建工作流，分别在 Windows 和 macOS runner 中构建并检查捆绑服务；工作流不携带本机配置或密钥，也不自动发布正式版本。

## 本地配置与隐私

真实密钥只保存在本机 `.env` 和私有模型配置中，不要写进源码、README、截图或提交信息。项目 `.env`、`data/`、用户记录和构建产物均被 Git 忽略；公开示例只使用占位地址和空密钥。

安装版把配置与数据保存在应用用户数据目录，不写入只读应用包。模型列表和普通状态接口不返回密钥；只有用户在本机设置页主动点击显示时才读取对应密钥。

如果将服务用于非本机场景，应配置 `GATEWAY_API_KEY`；请求通过 `X-API-Key` 或 `Authorization: Bearer` 鉴权。调用方密钥只应保留在自己的浏览器会话或本机配置中，不要把服务直接暴露到公网。

## 可选语音组件

源码保留可选 ASR 底层组件，不属于当前截图学习的必需依赖。默认 `ASR_PROVIDER=stub` 仅用于本地测试；可根据需要配置 `ASR_PROVIDER=sherpa_onnx`、`ASR_PROVIDER=aliyun_ws` 或 `ASR_PROVIDER=aliyun_nls_ws`。NLS 可使用 Token 或由 AccessKey 签发令牌。

相关诊断脚本：`scripts/download_sherpa_asr_model.py`、`scripts/check_aliyun_asr.py`、`scripts/check_aliyun_nls_asr.py`。配置语音服务不会自动启用录音；不要把这些底层组件视为现有截图界面的语音入口。

## 测试与诊断

```bash
pytest -q
```

```bash
node --test tests/*.mjs
```

测试默认使用模拟服务，不调用真实模型。真实接口可用以下脚本诊断：

```bash
python scripts/check_llm.py
```

输出 `LLM smoke test ok.` 表示真实调用成功；`LLM mock mode ok.` 只表示模拟链路正常。诊断脚本不应输出 API Key。
