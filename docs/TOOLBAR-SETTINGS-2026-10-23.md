# 短工具条、顶部题图与快捷设置

根据用户提供的两张 Gank 实拍参考图，调整默认窗口、题图位置、重置和快捷设置。本轮起点为 `2334580`，沿用已有答案分区，不重新推断 Gank 未公开的主进程实现。

## 展示与重置

- 启动显示 560×76 的短工具条；有题图时约 560×160，提示消息需要时再增加少量高度。旧版 780×760 的默认阅读尺寸不再撑大启动窗口。
- 每张题图以 112×64 独立缩略图放在工具条上方。回答后仍保留顶部题图，取消上一轮自动收到尾部的策略；多图横向滚动，可放大、删除，也可手动收起。
- 开始解题后展开阅读窗口，默认窄长 560×720；另有标准和宽屏布局，尺寸按当前显示器可用区域约束。阅读区与工具条各自成卡片，外层保持透明，不把图片放进背景。
- `⌘R` 与“重置”按钮走同一路径。生成中先中止并保留部分回答，再保存会话并清空本题视图、题图和分区；关闭快捷设置，回到短工具条。保存失败保留原内容并提示。语言、模型、主题等偏好不会被重置。
- `⌘N` 仍保留。新增 `resetView` 已同步到前后端快捷键配置和独立设置页；注册刷新只注销本进程实际注册的键位，不影响框选的临时 Escape。

## 齿轮中的真实设置

- 编程语言和回答语言：直接同步到共享复习设置；回答可选中文/English，正文语言进入提示词。固定分区标题继续遵循协议，以保证题型切换。此处没有宣称整个设置中心已国际化。
- 我的身份：面试者/面试官进入对话提示，分别强调作答要点或考察、追问和评价依据。保留用户明确题目的优先级，不虚构个人经历。
- 截图模型/面试模型：通过已配置接口的 `/models` 读取可选 ID，也可输入该接口支持的模型名称；分别持久化到 `VISION_MODEL` 和 `LLM_MODEL`。图片消息实际走截图模型，文本/面试默认调用走后者，继续复用现有接口与凭据。列表不可用时保留已配置模型并给出说明，不编造可用服务。
- 截图方式：局部/全屏真实作用于截图按钮与默认截图快捷键；显式全屏快捷键仍可直接抓全屏。
- 显示器：从 Electron 获取实际显示器，选择后作用于原生抓屏的目标和区域选择覆盖层；局部裁剪使用该屏内坐标与缩放系数，不叠加虚拟桌面的负坐标原点。显示器断开后回退当前主屏，保存失效 ID 会报错。
- 常用快捷键、透明度、回答尺寸与更多设置入口均可从面板访问。轻量设置使用 PATCH 合并，避免覆盖其它复习偏好；独立设置中心保存时也保留新增字段。

## 四种外观

白色、黑色、透明黑字、透明白字。白/黑模式支持 0%–100% 背景不透明度；透明模式去掉工具条、阅读卡片及代码块背景，文字保持清晰，设置面板保留可读底色。透明模式下代码按黑/白正文色显示，普通模式仍有语法高亮。

打开设置时窗口临时增高到至少 650px，面板内部可滚动；关闭后恢复工具条或阅读尺寸。默认工具条可直接点按，设置输入时才取得键盘焦点，关闭后恢复非焦点状态。
