## 对比后落实的改动

| 项目 | 本轮结论与处理 |
|---|---|
| 回答结构 | Gank 截图答案组件输出整篇 Markdown。删除左右自创的小节标签与重排，保留模型输出顺序。 |
| 阅读快捷键 | Gank 上/下一页按 `min(H, max(0.85H, 200))` 滚动。上一轮仍存在动态容器选择与自动追尾错误，已由后续阅读复核纠正；24px 自动跟随属于 Gank 语音组件，不能用于推断截图面板。 |
| 公式与代码 | 修复代码围栏中的 `$$` 被当作公式；补上 `$6$` 等数字公式；保留离线 KaTeX 与代码高亮。API 端口也能正确提供 vendor 字体/脚本。 |
| 中断后重试 | 真模型上游断流曾导致截图被标为已完成、同图无法再处理。现在保留部分答案，并保留截图的待处理状态，支持再次按处理键。 |
| 设置启动 | 修复 `assets.js` 在 DOM 常量初始化前调用引发的 TDZ 异常，以及 9958 服务发现尚未完成就请求配置的竞态。 |
| 会话/知识库/历史反馈 | 从互不共享的 Electron/browser localStorage 迁到本地共享 SQLite，按记录 ID 写入/删除，旧数据确认迁移后才标记完成，原快照保留。 |
| 保存失败 | 新对话先等待服务确认保存；失败时保留当前内容并提示，避免先清空后丢失。 |
| 跨来源访问 | 允许 Electron file/null 来源的 CORS；OPTIONS 预检交给 CORS 处理，实际 API 请求仍保留访问密钥验证。 |
| 快捷键 | 补回清空截图的注册与设置项；新保存的自定义键位不会再次被“旧默认迁移”覆盖。 |
| 发布一致性 | 前端同步脚本覆盖整个资源树，包含 select 页面与 vendor；9958 静态资源加 no-store，防止浏览器继续执行旧模块。 |

左右保留了自己的扩展：截图放大查看、最多 8 张待处理图片、紧凑模式、新对话 `⌘N`。Gank renderer 的重置默认是 `⌘R`；左右没有为追求键位一致而覆盖已有使用习惯。Gank 的 `slice(0,5)` 只能证明该组件最多展示五张缩略图，不能推断截图队列上限。

## 保留的边界与后续事项

1. 真实模型有明显延迟波动和一次断流，需继续对模型/上游服务做稳定性与延迟评估，不能声称达到 Gank 的响应速度。
2. 本轮没有实际触发 macOS 区域截图、权限首次授予、多显示器或各共享平台的隐藏效果；这些需要单独的系统场景验收。
3. 历史记录保存前 3 张缩略图与原图数量，不等于完整原图归档；左右的本地知识提取也不等于 Gank 的知识库能力完整复刻。
4. Gank 的代码复制/行号、其他求职场景不在本轮实现范围。主进程 `.jsc` 未覆盖的行为继续列为未知。
5. REA 安装仍在 `/tmp`；若被系统清理，需重新取得同一官方项目。本轮复用现有安装，没有修改 MCP 注册或安装全局运行时。
